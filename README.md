# OCS Portal Role Checker - IITH

A browser extension designed to help students keep track of new companies and roles on the OCS (Office of Career Services) portal of IIT Hyderabad (IITH).

## Features
- 🚀 **Automated Checking:** Scrapes and checks for new roles on the OCS portal.
- 🔔 **Notifications:** Alerts you when new companies or roles are added so you never miss an opportunity.

## Installation
1. Clone or download this repository to your local machine.
2. Open your Chromium-based browser (Chrome, Edge, Brave, etc.) and navigate to the extensions page (`chrome://extensions/` or `edge://extensions/`).
3. Enable **Developer mode** (usually a toggle in the top right corner).
4. Click on **Load unpacked** and select the directory where you saved this extension (`OCS_Portal`).
